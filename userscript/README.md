# MarkDone Lite userscript

Install (Tampermonkey, from URL):

https://raw.githubusercontent.com/veightz/AI-MarkDone/main/userscript/markdone-lite.user.js

Chinese guide: [`docs/userscript-lite/INSTALL-zh.md`](../docs/userscript-lite/INSTALL-zh.md)

Scope: right-docked two-level conversation directory (turns → headings, scroll-spy, pin/collapse), optional body reader (menu), page width, soft message-nav refresh, optional Cmd/Ctrl+Enter send (default off), settings panel (Lite ☰ → ⚙ 设置, or Tampermonkey menu), message step nav (▲▼, ←/→), CJK-aware word count, copy-as-Markdown. Not full extension parity — see the Lite vs 扩展 checklist in the Chinese guide.
