# 资料库与设置 UI 原型

状态：设计评审。按 2026-09-12 用户反馈精简；主导航只保留资料库和设置，取消未讨论的转换、重新关联、等待状态和设置附加视图。

当前方案使用两个轮流展开的侧栏模块。资料库展开显示书签 / 注释 / 高亮及书签文件夹，把设置按钮推到底部；点击设置后，它上移展开分类，资料库收成顶部按钮。切回时反向展开并保留选中位置。侧栏保留节点，用 360 ms 网格动画连续调整空间；支持减少动态效果，折叠区域不参与键盘焦点。右侧保留标题、搜索和单一圆角列表，每次只显示一种类型，每页最多 20 条。取消重复的顶部标签、文件夹下拉框和右侧设置分类。浅/深色通过设置切换。原有管理操作收进详情和“更多”。高亮详情只有引用、颜色、来源页面和删除；注释沿用正文编辑。

启动：仓库根目录运行 `npm run dev -- --host 127.0.0.1 --port 5197`。

- 页面：`http://127.0.0.1:5197/mocks/components/bookmarks-workspace/prototype/preview.html`
- 图标：同目录 `icons/index.html`
- 重新生成页面：`node mocks/components/bookmarks-workspace/prototype/build-preview.mjs`
- 重新生成图标：`node mocks/components/bookmarks-workspace/prototype/icons/build-icons.mjs`
- 重新生成设置盘点：`node --import tsx mocks/components/bookmarks-workspace/prototype/build-inventory.mjs`

页面与图标板均为自包含 HTML。页面选区与消息胶囊示例通过 `?view=demo` 进入，图标稿通过单独链接进入，均不占产品主导航。外观与设置不连接扩展数据；只有在示例回复上创建的高亮写入专用浏览器存储。示例条目来源为 ChatGPT 首页，手动高亮来源为本示例页。它们不代表真实会话。

已在内置浏览器检查：分类搜索、输入增强父子项、浅深色、布局切换、选区三色与刷新恢复；精简后检查高亮没有注释编辑框，并有原页链接。SVG 已验证 XML、viewBox、统一笔画属性及浅深色渲染。原型不替代真实 ChatGPT、迁移、并发或最低浏览器版本验收。

最终决策与索引方案见 `docs/plans/2026-09-11-chatgpt-library-settings.md`。确认设计后重新实现为生产组件，再清理原型。

开发者渲染检查可使用 `?fixture=large`，生成 10,000 条纯示例记录并验证 DOM 每页上限；这个参数不是产品功能，也不是实际插件性能验收。

本轮已用 10,000 条示例记录检查：第一页 20 行，翻页后仍为 20 行；切到高亮只渲染高亮当前页，书签列表不留在 DOM。该检查证明原型的渲染上限，不是实际插件性能测量。

侧栏交互已在内置浏览器检查：设置按钮往返移动、设置分类切换、模块间保留文件夹和分类、折叠区域的 `inert` 与展开状态、右侧分类去重。后续组件验收重点：动画中快速反向切换、短窗口分类滚动、键盘连续导航，以及系统减少动态效果偏好。
