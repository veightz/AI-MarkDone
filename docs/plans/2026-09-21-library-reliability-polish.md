# 资料库可靠性与排版修正

本轮范围：修复资料读取与设置返回问题，核对现有管理生命周期，收敛字号、垂直对齐和消息胶囊。保留书签存储、内容发现、选区定位、计数和现有高亮/注释格式，不增加新的资料类型或转化动作。

## 已复现的原因

1. 安装版资料库报错时，`ping`、高亮及注释只读请求可响应，`markLibrary:get` 无有效响应；磁盘包已含新接口，运行后台仍来自此前构建。重新加载扩展并刷新空输入框的 ChatGPT 页面后，原资料恢复读取，未删除或迁移记录。
2. `LibraryMarksView` 原先等待目录成功后才请求正文，目录失败导致全部资料被隐藏。现改为并行读取、独立失败处理；目录不可用时展示来源资料，禁用目录写入，显式重试。
3. 信息页点击分类只过滤了未显示的 Settings 内容。分类现在显式请求 shell 切换，回归校验可见内容及标题，不只检查左侧选中态。
4. 主模块按钮的 50px 最小高度超过侧栏轨道高度；旧字号、材质和 padding 规则叠加。已修正尺寸责任，统一字号层级和居中方式。
5. 消息胶囊改用 border-box 后，计算宽度未包含完整内边距，真实浏览器复现末端按钮裁切 5px。已修正计算并加入宽/窄窗口实际点击。
6. 关闭的 Directory 预览只有 `opacity: 0`，仍拦截鼠标。已同时关闭 visibility 和 pointer-events；不改目录数据、定位或内容发现。

## 管理层级与边界

左侧文件夹筛选，右侧网页/对话横条展开当前类型条目。归类键来自 `platform + conversationId`，不直接按完整 URL 字符串分组；URL 保留用于打开原页，自定义名称不参与身份。文件夹及名称由高亮和注释共享，原书签独立。

现有生命周期覆盖创建、读取与搜索、对话展开、名称修改、归档及文件夹移动、条目编辑/改色、批量处理、取消、失败重试、重新打开与原页跳转。文件夹删除保留必须为空规则；删除某类型条目不删除另一类型或原网页。完整标记备份仍未纳入原书签备份，不扩大此前已确认的备份范围。

性能边界：对话每页 20 组、正文最多挂载 20 条、文件夹树最多 40 行；单次投影中每个网页只解析一次标题。统一 SVG 外壳通过有 pure 标记的独立导出复用，保留未使用图标剔除与原包体积预算。

## 标题保存与底部入口间距补修

- 根因：页面初始化时可能没有标题，保存时没有再次读取；PageAnnotationStore 同身份绑定会忽略新的显示元数据；注释后台已有 bundle 不合并新标题；高亮同色重试提前返回，其他写入又可能用空值覆盖已存标题。
- 修复：在页面和 Reader 新增标记时读取匹配页面标题；同身份注释绑定仅刷新元数据，不重新加载或清空记录。后台成功写入时补齐标题和来源 URL，空值保留原值；高亮同色重试仅在元数据变化时写入，不变更标记 revision。复用现有 document.title，无 schema 迁移、无额外请求/监听器，不触碰自定义名称目录。
- 底部好友迹、请我喝咖啡：沿用现有布局和材质，将链接间距与卡片内部间距统一为 space-2，卡片上留 space-1。
- 验证：先复现四个失败测试，再完成修复；最终 8 文件 / 92 项相关测试通过，包含真实选区色块和注释保存弹窗入口、延迟标题、同色重试、空值保护、旧数据与自定义名称。Chrome/Firefox 构建及原预算通过（content feature graph gzip 464.98 / 465 kB）；组件验收 Chromium/Firefox × 浅深色通过，新增底部间距断言。当前 ChatGPT 页面只读核实 document.title 和既有侧栏链接均可读；未在用户真实资料中新建或修改记录，也未把历史安装版验收算作本补修验收。
- 边界：未访问且历史缺失标题的记录不会自动回填；后续取得标题并成功保存时补入，资料库自定义名称仍优先。刷新构建后的扩展再使用新保存逻辑。
