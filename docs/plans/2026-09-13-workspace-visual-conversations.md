# 资料库与设置：视觉对齐、对话筛选与批量处理

## 已确认范围

- 对照 `mocks/components/bookmarks-workspace/prototype`，统一顶部、侧栏与正文背景，加强浮层边缘、外阴影、浅色反光与磨砂材质；主导航和分类字号随现有字号设置缩放。
- 注释与高亮在左侧按对话筛选，提供全部对话；以现有 document/conversation ID 分组，标题相同的对话保持独立。不改原始存储。
- 批量删除注释/高亮，批量修改高亮颜色。进入批量模式才显示选择控件；本页选择最多 20 条，翻页保留，切换类型/对话/搜索清空。
- 删除确认显示条目数和对话数；逐条复用现有修订校验接口。成功、缺失与失败按实际结果计数，失败项保留供重试；保存成功而刷新失败时仅重试读取。

## 组件检查表

| 组件 | 本轮对齐要求 |
|---|---|
| 外壳与遮罩 | 在 ChatGPT 明暗正文上边界清晰；阴影与边缘反光统一；模糊只在外层，不对每条记录增加滤镜 |
| 顶部与双模块侧栏 | 消除白色标题带；统一主背景与标题层级；分类和文件夹/对话文字不使用微小字号 |
| 搜索、下拉、按钮、步进器、开关、滑块 | 统一内凹输入、轻凸按钮、圆角、焦点、禁用与按压状态 |
| 记录与详情 | 20 条分页；可读的引用/正文；详情、关闭、原页和编辑操作保持完整 |
| 文件夹树与对话导航 | 标签与计数分开；长标题截断，完整标题可访问；长列表限制挂载数量 |
| 更多菜单与批量栏 | 同一浮层材质；键盘可达；明确选择范围和取消出口 |
| 新建、重命名、移动、删除、导入与备份窗口 | 与外壳共用材质配置，保留原确认、验证和失败重试行为 |
| 注释模板及设置次级窗口 | 使用同一配置控制背景、边缘和表单；保持原业务接口 |
| 空、加载、失败、部分完成 | 简短且可操作；失败不显示为空或成功 |

## 实现与验证

视觉配置沿用 Reference → System → Public 与 Shadow DOM；工作区组件共用一个材质样式入口，不修改 Reader/导出等其他区域的全局基础样式。先核对真实组件，再跑资料库/设置/业务窗口的浅深色、中英文、窄屏、缩放与减少动态效果检查。新增功能通过真实面板入口测试，最后执行 build 与相关门禁。

状态：本轮实现、核心回归、构建及浏览器组件验收完成；安装版真实 ChatGPT 验收仍独立待完成，不以夹具测试替代。

### 实际交付

- `workspaceMaterials.css` 是资料库、设置及其业务窗口的共用材质入口；保留现有主题快照和字号缩放。标题移入正文区域，去掉与侧栏割裂的白色横条。默认模块字号为 16px，分类和记录主要文字为 15px。
- `LibraryConversationNavigation` 从真实记录生成内存对话列表，以 document key 区分同名对话；对话较多时提供搜索，最多挂载 40 个对话按钮。右侧继续每页最多 20 条。当前对话最后一条移除后回到全部对话。
- 批量模式复用现有逐条 CRUD 和修订校验，没有新增后台协议或持久化索引。翻页保留选择，切换范围清空；部分失败仅保留失败项；取消不写入，读取重试不重复写入。批量栏保留 DOM 与键盘焦点。
- 实际组件检查修正了隐藏按钮被基础样式重新显示、模板保存按钮白底白字、搜索框双重边框、书签菜单受面板变换影响而定位越界等遗漏。后续验收必须经过真实入口并检查嵌套组件，不能只比对顶层布局。
