# ChatGPT UI 与高亮实施记录

用户已批准分阶段实施。此文记录执行状态；能力真相继续归属 FEATURES，接口归属 contracts 与 RUNTIME_PROTOCOL，样式归属 design。

## 固定边界

- 重绘资料库、设置、选区弹窗、消息胶囊与右下角入口；全插件清理中英文无效文案。
- 保留书签、注释、内容发现、定位、计数与导出核心逻辑及数据格式；只独立新增高亮存储和时间只读接口。
- 高亮仅支持 ChatGPT 页面和 Reader 助手回复，选区弹窗提供复制、注释与蓝黄红三色色块；不再实现画笔模式。
- 时间从网站已被动捕获的数据按消息 ID 读取，优先 update_time，其次 create_time；缺失不显示。不请求会话、不打开宿主菜单、不读取 React 内部结构。
- 分类型列表每页 20 条，文件夹保留层级与窗口化；不建立重复的持久化资料库。
- 采用既有 AppearanceSnapshot / AppearanceScope / Shadow DOM / --aimd-*；不引入样式框架或扩大支持平台。

## 已发现并修正的验收问题

- 动作结束会覆盖外部禁用状态：补充胶囊真实入口复现并保留 disabled。
- 高亮矩形遮住文字：先记录失败检查，再按浅/深色合成整个标记层，浏览器确认文字与高亮同时可见。
- 少量记录导致侧栏高度收缩；隐藏批量控制仍可聚焦：补充结构回归，shell 填满剩余空间，批量栏使用 hidden/inert。
- 服务层直接引用 runtime client：把 HighlightSession 放到 UI 投影层，保留架构门禁。
- 新功能超过体积预算：静态 CSS 使用现有 Vite 压缩，图标按需引用，并清理 FAQ 冗余文案；不放宽预算。
- 深色 Shadow DOM 没有主题属性时仍用浅色混合：将混合模式收归 Appearance 语义令牌，Chromium/Firefox 的深色高亮实测通过。
- 文件夹选择器与排序动作仍引用旧图标：统一接入圆角 SVG；公共高亮测试夹具补入 Git 跟踪范围，检查所有新增本地依赖未被忽略。
- 性能测试曾在语言包初始化期间开始节点稳定性采样；诊断记录显示 200 个消息 key 未变、一次语言更新重绘全部工具栏。夹具改为等待语言初始化完成再取稳定节点样本，冷启动统计仍包含初始化过程，所有数值预算和节点一致性断言保留。
- Reader 表现层测试曾在关闭动画兜底回调结束前移除 DOM，导致 Vitest 退出时出现 `document is not defined`。测试清理改为先完成原关闭动画生命周期，再移除宿主；生产 Reader 生命周期未改动。
