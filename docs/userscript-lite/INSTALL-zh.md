# MarkDone Lite（油猴）安装

Lite = 日用阅读子集（视口跟随阅读器、大纲钉住、页面宽度、软刷新消息导航、消息步进、字数统计、复制 Markdown、Cmd/Ctrl+Enter 发送、设置面板）。**不是**全功能 Chrome 扩展；Drive / 书签库 / 导出等仍用解压扩展。

## 安装（Tampermonkey）

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开仪表盘 → **实用工具** → **从 URL 安装**，粘贴：

```
https://raw.githubusercontent.com/veightz/AI-MarkDone/main/userscript/markdone-lite.user.js
```

3. 确认安装。之后 Tampermonkey 会按 `@updateURL` 自动检查更新（同 Sensebook）。

本地调试：把仓库里的 `userscript/markdone-lite.user.js` 拖进 Tampermonkey「添加新脚本」或复制粘贴。

## 使用

打开 [chatgpt.com](https://chatgpt.com) 任意对话，右下角会有一排三个按钮：

| 按钮 | 作用 |
| --- | --- |
| **📖 阅读器** | 在右侧侧栏打开「当前正在读的那条」助手回复（视口里的主读回复；找不到就用最后一条）。 |
| **↔ 宽度·标准** | 页面宽度。每点一次切换：**标准 → 较宽（最多约 1200px）→ 铺满**。会记住，刷新 / 切换对话后仍生效。 |
| **🔄 软刷新**（默认隐藏） | 在「设置」里打开「软刷新按钮」后才出现在右下角；默认只在 Lite ☰ 菜单里。 |
| **Lite ☰** | Lite 菜单：阅读器、大纲钉住开关、**⌨ Cmd/Ctrl+Enter 发送 开/关**、宽度三选一（标准 / 较宽 / 铺满）、软刷新导航、**⚙ 设置…**；底部显示版本号、「检测到 N 条助手回复」、宽度容器状态、发送键状态。 |

各功能：

- **阅读器 chip（📖 阅读器）**：滚动对话时，跟着视口里正在读的那条助手回复出现在它右上角；窄屏（< 720px）改为固定在右下按钮上方。点它 = 打开侧栏阅读器。
- **侧栏阅读器**：顶部「宽度·标准 / 较宽 / 铺满」切换阅读器自身宽度（也会记住）；「关闭」或按 `Esc` 关闭。
- **大纲钉住**：阅读器右侧是这条回复的大纲（标题 / 编号段落），点条目跳转。📍 = 悬停才展开，📌 = 钉住常显；也可在 Lite 菜单里切换。记住上次选择。
- **软刷新导航**（Lite 菜单里）：只重扫**当前活动页**（`data-app-shell-active-page="true"` 下的 `main`，否则取第一个可见 `main`）里已挂载的消息，默认**不**整页刷新；缺洞时 toast 里可选「仍可整页刷新」。切换会话时会跟着换页，不会扫到隐藏的旧对话。

## 设置入口（在哪找）

三个入口，任选其一：

1. 右下角 **Lite ☰** → **⚙ 设置…**（弹出设置面板；`Esc` 或点遮罩关闭）。
2. Tampermonkey 图标 → 本脚本下的菜单命令 **「MarkDone Lite 设置」**（另有一条「Cmd/Ctrl+Enter 发送 开/关」快捷开关）。
3. 发送键开关另外直接放在 **Lite ☰** 菜单里：**⌨ ⌘/Ctrl+Enter 发送：关/开**，不用进设置面板。

设置面板里的项目（全部会记住，**恢复默认**按钮一键还原）：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| ⌘/Ctrl+Enter 发送 | **关** | 开启后 ChatGPT 输入框里 **Enter＝换行**，**⌘+Enter（Mac）/ Ctrl+Enter（Win/Linux）＝发送**；Shift+Enter 仍是换行。输入法选字时的 Enter 不受影响。 |
| 大纲钉住 | 关 | 阅读器右侧大纲常显（关＝悬停展开）。 |
| 默认页面宽度 | 标准 | 标准 / 较宽 / 铺满。 |
| 阅读器宽度 | 标准 | 侧栏阅读器自身宽度。 |
| 软刷新按钮 | 关 | 是否在右下角显示「🔄 软刷新」。 |
| 消息步进 | **开** | 右下角 ▲ ▼ 按钮，跳到上一条 / 下一条助手回复；菜单里也有。 |
| ←/→ 键步进 | **开** | ← 上一条、→ 下一条。**只在没在输入框里打字、没选中文字、没按修饰键、没开弹窗时生效**；需先开「消息步进」。 |
| 字数统计 | **开** | 阅读器小标签「📖 阅读器 · N 字」和侧栏顶部显示本条回复字数（鼠标悬停看中日文/英文拆分）。 |
| 复制 Markdown | **开** | 小标签上的「📋 MD」、侧栏顶部「复制 MD」、Lite ☰ 菜单「复制当前回复 Markdown」。 |
| 跟随阅读小标签 | 开 | 滚动时跟在当前回复旁的「📖 阅读器」小标签（字数和 📋 MD 都挂在它上面；关掉后用菜单 / 侧栏）。 |

### ⌘/Ctrl+Enter 发送：行为细节

- 只作用于 ChatGPT 主输入框（`#prompt-textarea` / 统一输入框里的 contenteditable），别处的输入框不受影响。
- 默认关闭＝完全保持 ChatGPT 原生（Enter 发送），装上 Lite 不会改变你的打字习惯；要用请在菜单里打开。
- 输入法（IME）选字中的 Enter / Cmd+Enter 一律放行，不会误发、不会多出换行。
- 发送优先点输入框旁的「发送」按钮；没找到可用按钮时，改为向页面回放一次 Enter。输入框为空时 ⌘/Ctrl+Enter 什么也不做。
- 自己的实现，思路对齐扩展里的「输入增强 → Enter 换行」，**不含**扩展的加粗 / 列表 / 公式增强。

### 消息步进 / 字数统计 / 复制 Markdown：用法

- **步进**：右下角 **▲ / ▼**（或键盘 **← / →**）在助手回复之间跳转。读到一条的中间时，▲ 先回到这条开头，再按才去上一条。到头会提示「已经是第一条 / 最后一条」。阅读器开着时，步进会连阅读器一起换成目标那条。
- **字数**：中日文每个字算 1，英文每个单词算 1；代码块、公式、按钮不计。标签上写的是合计，悬停看拆分。
- **复制 Markdown**：点小标签的 **📋 MD**，或阅读器顶部 **复制 MD**，或 Lite ☰ → **复制当前回复 Markdown**。输出保留 `#` 标题、粗体/斜体/行内代码、链接、嵌套有序/无序列表、引用、表格（含对齐）、围栏代码块（带语言；代码里有 ``` 时自动加长围栏）、`$公式$` / `$$公式$$`、分隔线。
- 以上都只扫**当前活动页的 main**，不会读到隐藏的旧对话。
- Markdown 转换是 Lite 自己写的 DOM→Markdown，遇到 ChatGPT 的特殊组件（图表卡片、引用 chip 等）可能与扩展的输出不同；发现不对请把那条回复的截图和复制结果一起发回来。

排错：如果菜单底部显示「检测到 0 条助手回复」「未找到 active main」或「未找到宽度容器」，说明 ChatGPT 页面结构又变了，截图（含菜单）发回来即可。点「较宽」后中间栏应明显变宽（吃掉两侧空白）；若按钮已显示「宽度 · 较宽」但版面没变，也截图发回。

## Lite vs 扩展（功能清单，勾选想要的我来补）

Lite 只有「纯页面 DOM」能做的日用子集；没有 `chrome.*`、没有后台、没有本地数据库，所以凡是要**存数据 / 跨页 / 跨设备 / 导出文件**的，Lite 都没有。工作量为粗估（一人一天约 6 小时）。

### 已有（Lite ✅ ＝ 扩展 ✅）

- [x] 阅读器侧栏（单条回复，含目录）／视口跟随小标签
- [x] 大纲钉住
- [x] 页面宽度（标准 / 较宽 / 铺满）
- [x] 软刷新消息导航（只扫当前活动页）
- [x] ⌘/Ctrl+Enter 发送（Enter 换行；默认关）
- [x] 消息步进：右下角 ▲▼ 按钮 + ←/→ 键（默认开）
- [x] 字数统计：中日文按字、英文按词，不含代码块和公式（默认开）
- [x] 复制 Markdown：保留代码围栏与语言、缩进、表格、列表、标题、链接、公式（默认开）
- [x] 设置面板（上表各项）

### 我的判断（先做哪些最划算）

1. **消息步进（←/→ 键）**、**字数统计**：各半天，纯 DOM，日用价值高。
2. **复制 Markdown**（含导出 Markdown）：日用最高频，但是 1–1.5 天，值得单独立项。
3. **每条消息工具栏**：有了它复制/阅读器才顺手，但最依赖官方 DOM。
4. 书签 / 注释 / 高亮 / 资料库 / 导出 PDF·PNG / Drive：体量大且需要存储与后台，**继续用扩展**，Lite 不追。

> 上表剩下的项都没有实现，只列了 TODO。

## 与 Chrome 扩展并存

- Lite DOM id / class 前缀为 `mdlite-`，尽量不与扩展 `aimd-` 抢节点。
- 同开可能出现两套入口；日常可只开 Lite，应急再解压装扩展。
