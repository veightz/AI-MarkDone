## 详细说明

```
MarkDone（veightz）是开源扩展 AI-MarkDone 的个人维护改版（fork），面向自己的 ChatGPT / Gemini / Claude / DeepSeek 阅读与导出工作流。

与 Chrome 商店「原版 AI-MarkDone」不是同一商品。本扩展以未列出（Unlisted）方式分发，仅供持有安装链接的人使用。请不要与商店原版同时开启，以免抢同一页面。

主要能力（随版本迭代）：
• 阅读器跟随视口：主入口贴着当前主读助手回复
• 文内大纲与钉住：大纲可跳转；可钉住常驻或保持动态收起
• 划选 / 消息工具条常显
• 阅读器宽屏选项
• 刷新消息导航默认软刷新（重扫已挂载 DOM），整页刷新仅作兜底
• 书签、Prompt、Markdown / PDF / PNG 等导出（继承上游能力）
• 可选 Google Drive 书签备份（需你本人授权；新商店 ID 下可能需重新配置 OAuth）

隐私：
• 核心处理在本地浏览器完成
• 本 fork 不向开发者自建服务器上传你的对话内容
• 可选 Drive 备份时，文件直接进入你自己的 Google Drive

安装建议：
• 装本未列出版之前，请先禁用或卸载商店原版与旧的「加载已解压」开发包
• 开发调试仍可用 GitHub Releases 解压包；日常请用本商店链接以便自动更新

开源仓库：https://github.com/veightz/AI-MarkDone
上游项目：https://github.com/zhaoliangbin42/AI-MarkDone（MIT）
```
