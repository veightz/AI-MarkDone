## Detailed description

```
MarkDone (veightz) is a personally maintained fork of the open-source AI-MarkDone extension. It speeds up reading, navigation, bookmarks, prompts, and Markdown/PDF/PNG export on supported AI chat sites (ChatGPT, Gemini, Claude, DeepSeek).

This is not the same Chrome Web Store item as the upstream “AI-MarkDone”. This fork is distributed as Unlisted for personal use via the install link. Do not enable it together with the store original—both inject into the same pages.

Highlights (evolve with releases):
• Follow-viewport reader: primary entry tracks the in-view assistant reply
• In-reader outline with pin: jump sections; pin to keep open or keep auto-collapse
• Always-visible selection / message toolbar
• Widescreen reader option
• Soft refresh for message navigation (re-scan mounted DOM by default; full reload only as fallback)
• Bookmarks, prompts, and export flows inherited from upstream
• Optional Google Drive bookmark backup (your account only; may need OAuth rebind under a new store extension ID)

Privacy:
• Core processing stays local in your browser
• This fork does not send your chat content to a developer-operated backend
• Optional Drive backups go directly to the Google Drive you authorize

Install tips:
• Before installing this Unlisted build, disable or remove the store original and any old “Load unpacked” copy
• Unpacked GitHub Release zips remain for development/emergency; prefer this store link for auto-updates day to day

Source: https://github.com/veightz/AI-MarkDone
Upstream: https://github.com/zhaoliangbin42/AI-MarkDone (MIT)
```
