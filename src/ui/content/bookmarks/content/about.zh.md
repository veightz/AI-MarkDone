# 关于作者

我是一名工科研究生，平时经常用 ChatGPT 阅读和写作。做 AI-MarkDone，是想让每天反复做的事情更顺手：阅读长回复、复制公式、保存有用的内容，以及准备后续提问。

## 为什么我会做 AI-MarkDone

这个项目最初来自我工作中的三个问题。

1. 复制公式需要额外整理。公式有时显示不出来，复制的 Markdown 粘贴到 Typora 后也常常需要手动修正。我还希望能直接复制某个公式，不必先复制整条回复再从中提取。

2. 长对话不容易查找和阅读。公式多、内容长时，页面滚动可能变慢。我希望有一个排版清楚的阅读界面，也能方便地回到需要的段落。

3. 复用回复的步骤太多。我希望能导出选中的消息，把有用的回复存成书签，并给具体段落写下修改意见。继续提问时，可以直接带上这些注释，不必再逐一描述要改哪里。

AI-MarkDone 就是从这些需求中慢慢做起来的。它关注的仍是围绕对话展开的这些操作：阅读、复制、导出、保存书签和添加注释。

大家的反馈让我知道，哪些细节也在影响其他人的使用：公式复制、导出、内容整理，或别的具体操作。我会结合这些实际体验，决定接下来改进什么。

感谢你使用 AI-MarkDone，也欢迎分享使用体验。它是一个个人项目，你的反馈能帮助我继续把细节做好。
